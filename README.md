# One Word for Your Wi-Fi — Flaky

Home Wi-Fi is a flaky friend: there one minute, gone the next, always at the worst possible moment — mid-call, mid-download, one bar in the bathroom — and it only ever comes back after you unplug the router and count to ten. One word, instantly understood, and it would make a perfect network name.

> Flaky

Character count: 5

## How to run

```sh
python3 main.py
```

This writes the entry word to `/output/entry.txt` (or `$OUTPUT_PATH` when set).
